# forma.

Тренировки в зале 3 раза в неделю (A · B · C), веса на следующий раз, журнал, белок и прогноз.
Сайт: https://forma-ua.github.io

- Данные хранятся на устройстве (localStorage + IndexedDB). Сервера нет.
- Вход через Google (Google Identity Services, проект `forma-514515`): копия данных в скрытой папке приложения на Google Диске (`drive.appdata`). Приложение в режиме тестирования — войти могут только тестовые пользователи из Google Cloud → Google Auth Platform → Audience.
- Apple Health / «Фитнес» / Yazio приходят через быструю команду iOS «forma sync» (инструкция — в приложении: Настройки → Синхронизация).
- Фото упражнений из гида лежат в приватном репозитории `forma-ua/forma-media` и скачиваются на телефон по ключу доступа только для чтения.

## Файлы

```
index.html            оболочка
css/app.css           стили, светлая и тёмная тема
js/data.js            упражнения, мышцы, программа A/B/C, разминка
js/guide.js           упражнения из гида «Таз в движении» (без фото)
js/app.js             экраны, прогрессия весов, восстановление мышц, рекорды, калькуляторы, синхронизация, Google Диск
sw.js                 офлайн-режим (меняй VERSION при обновлении)
manifest.webmanifest  установка на экран «Домой»
```

## Как обновлять

Изменить файлы → загрузить в репозиторий → в `sw.js` поднять `VERSION`. GitHub Pages обновит сайт за 1–2 минуты.
